## 2024-05-24 - Concurrent Script Loading for CDN dependencies
**Learning:** The application loads various external libraries (like pdf.js, mammoth, jszip, etc) on-demand based on conversion types. Previously, `ensureConversionLibs` was using a `for...of` loop with `await` to load these scripts sequentially. This creates an unnecessary waterfall of network requests, especially when multiple libraries are needed simultaneously (e.g., pdf -> docx requires pdfjs, jspdf, jszip).
**Action:** When dynamically loading multiple independent external scripts, always use `Promise.all` to fetch them concurrently instead of sequential `await`s. This significantly reduces the total load time (Time to First Byte for the scripts) and accelerates the start of the actual conversion process.
